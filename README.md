# ReadNest 音阅视界
一站式个人媒体库：把 WebDAV / 本地来源里的**文档、音频、视频、图片**统一收纳、浏览、播放与阅读



## 一、文档

覆盖格式：**PDF / EPUB / MOBI / TXT / CBZ / CBR / JSON / Markdown / 直播源（m3u、txt）**。

- **TXT 智能阅读**

  - 自动识别编码（UTF-8 / UTF-16 / GBK 等）并归一化，杜绝乱码；

  - 自动章节切分与章节目录，支持跳章、目录定位；

  - 精确到字符偏移的进度记忆，重新打开回到原位置；

  - 断点续传下载大文件，网络中断重试不重头。

- **JSON 阅读器**：树状展示，节点以 **+ / −** 号展开收缩（展开才构建子树，大文件不卡顿）；键值行带语法着色，**点击任意值一键复制**。

- **Markdown 阅读器**：GitHub Flavored Markdown 完整渲染——标题、列表、表格、任务列表、引用、链接、内联 HTML 全部支持；代码块带语法高亮（关键词 / 字符串 / 数字 / 注释着色），可横向滚动。

- **直播源支持**

  - `.m3u`（含 `#EXTINF` 频道名）：解析后直接进入频道播放列表；

  - `.txt` 双格式兼容：命中较多「频道名,地址」行（≥3）按直播源打开，否则仍按电子书阅读；

  - 频道列表作为播放器选集，上方显示源文件名（「频道 · 共 N 台」），点频道即播；

  - 播放走 mpv 内核并**跟随系统代理**（代理软件开启时海外源可正常播放）。

- **PDF / EPUB**：内置渲染器阅读；EPUB 原生解析章节；进度自动保存。

- **MOBI / CBZ / CBR**：转为可读内容打开（MOBI 转换器 / 压缩包解析）。

- **通用体验**：打开即缓存（含 json/md/m3u）、字号与阅读设置记忆、进度同步到「历史记录」；所有文本缓存可在「缓存管理」手动维护。

## 二、音频

- **后台播放**：基于 audio\_service，锁屏/通知栏可直接控制（播放/暂停、上一曲、下一曲），系统媒体会话每秒同步进度。

- **智能播放队列**：点开任意音频，自动把**同目录下全部音频**按自然排序（1、2、…、10 不混乱）加入队列，续听不中断。

- **播放模式**：顺序播放 / 单曲循环 / 列表循环 / 随机播放，一键循环切换。

- **记忆续播**：每首音频记录播放位置，再次打开从上次位置继续。

- **迷你播放器**：页面底部常驻播放条——播放模式、上一曲、播放/暂停（大按钮）、下一曲与实时进度条；点击可展开完整队列。

- **远端直连**：WebDAV 认证与浏览器 UA 直接走 ExoPlayer 原生下载；缓存文件优先本地秒开；缓存可在「缓存管理」中手动维护。

- **容错**：播放失败自动跳过重试；服务器按 UA 过滤的（502/404）场景已内置规避。

***

## 三、视频

内核为 **mpv**，重点面向远端 4K 流媒体的流畅播放。

- **播放能力**

  - 4K / HDR（H.265）硬解播放；fMP4 分段视频深度预读，拖动进度条稳定落位；

  - 内嵌/外挂字幕渲染（含 PGS 图形字幕），音轨、字幕轨道一键切换；

  - 倍速播放：1x / 1.25x / 1.5x / 2x / 3x 循环切换，**长按画面**瞬时 3 倍速快进；

  - 记忆续播：打开后自动跳回上次看到的位置。
  - 小窗播放：安卓原生画中画
  - 后台播放：后台继续播放，提供常驻通知栏控制播放/暂停

- **选集**：自动聚合**同目录同来源**的全部视频为选集，列表顶部显示文件夹名，支持上一集/下一集快速切换。

- **手势操控**：左右滑动快速 seek（带时间浮层）；屏幕左半区上下滑调亮度、右半区上下滑调音量；双击播放/暂停；单击显示/隐藏控制层。

- **网络韧性**

  - 断流 15 秒自动暂停并弹出「重试」按钮；

  - 打开失败自动重试一次（网络抖动自愈）；

  - WebDAV 认证 + 浏览器 UA 直连，兼容自签名证书与 UA 过滤型 WAF。

- **播放完成**：弹出「下一集 / 从头播放」选择框，默认下一集，5 秒无操作自动播放下一集。

- **视频信息面板**：ⓘ 一键查看文件名、所在文件夹、分辨率、帧率、视频码率、编码格式、音频参数、时长与文件大小。

- **真实缓冲显示**：绿色缓冲条跟随实际下载节奏渐进推进，不虚标。

## 四、图片

- **格式识别**：jpg / jpeg / png / gif / webp / bmp / heic / avif。

- **图片浏览器**：点开任意图片自动聚合**同目录全部图片**进入预览页。

- **瀑布流预览**：按每张图片真实宽高比排版，支持 1 行 4 / 2 / 1 列切换；缩略图按 360px 缩放解码，多图加载快、内存占用低。

- **沉浸式看图**

  - 两种浏览模式：**左右滑动**（逐张翻页）与**上下拼接**（连续浏览），一键切换，页码实时跟随；

  - **双指缩放**（0.6x\~8x，以双指中点为焦点，跟手零延迟），放大后单指拖动查看，缩放时自动冻结翻页/滚动；

  - 点按屏幕中央显隐工具栏。

- **缓存与重试**

  - 预览时即写入本地磁盘缓存，沉浸式浏览直接取缓存，不重复拉取；

  - 8 路并发下载 + 失败自动重试（1.5 秒间隔，界面保持加载态）；

  - 「缓存管理」中单独显示图片缓存总大小，支持一键清理（含内存缓存，即时生效）。

- 浏览过的图片自动进入「历史记录」。

***

## 五、内容库与来源管理

- **多来源**：同时挂载多个 WebDAV / 本地目录来源，统一展示、切换浏览。

- **目录浏览**：在线目录树导航，保留文件夹结构；刷新时自动清理云端已删除的条目。

- **搜索、排序**：文件名搜索；按修改时间 / 文件名（自然序）排序。

- **收藏**：任意条目加入收藏，首页「我的收藏」直达。

- **下载队列**：任意条目加入下载，支持暂停/恢复/删除；下载完成的文件本地直读播放。

- **缓存管理**：音频/文档缓存列表（可单独重新缓存或删除、一键清理全部）；图片缓存独立统计与清理。

- **首页**：「历史记录」展示最近打开的 2 条内容（可查看全部），问候语与收藏快捷入口。

- **缓存管理**：音频/文档缓存列表（可单独重新缓存或删除、一键清理全部）；图片缓存独立统计与清理。

- **首页**：「历史记录」展示最近打开的 2 条内容（可查看全部），问候语与收藏快捷入口。
