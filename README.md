## 📖 软件简介

**ReadNest（音阅视界）** 是一款面向个人资料管理的 Android 应用，用于统一整理和打开本地文件、WebDAV 文件、外部分享文件以及外部链接内容。

它可以将以下内容集中到一个应用中：

- 📚 PDF、EPUB、MOBI、TXT、Markdown、JSON 等文档
- 🎧 音频文件和后台播放队列
- 🎬 普通视频、M3U8、M3U/TXT 直播源
- 🖼️ 图片和图片目录
- 📦 CBZ、CBR 等漫画压缩包
- 🌐 WebDAV、本地目录和外部链接

ReadNest 不提供媒体资源本身。应用中的文件来自用户自己的本地存储、WebDAV 服务、分享内容或用户输入的网络地址。

## 🧭 主界面入口

应用底部主要包含四个入口：

```text
ReadNest 主入口
├── 🏠 首页       最近打开、收藏、添加外部链接
├── 📚 内容库     浏览文件、文件夹、搜索、排序和管理
├── 🌐 来源       添加本地文件夹或 WebDAV 来源
└── ⚙️ 设置       阅读参数、后台播放、下载和缓存管理
```

底部还可能显示音频迷你播放器，方便在浏览其他页面时继续控制音频。

## 🚀 快速开始

### 第一步：添加来源

首次使用建议先进入：

```text
来源 → 授权本地文件夹
```

或：

```text
来源 → 添加 WebDAV 服务器
```

添加完成后，应用会把文件和文件夹写入内容库。远程目录通常按需读取，进入深层文件夹时再扫描对应目录，以减少首次加载时间。

### 第二步：打开内容

进入：

```text
内容库 → 选择来源 → 进入文件夹 → 点击文件
```

应用会根据文件扩展名和内容类型自动选择合适的阅读器或播放器。

### 第三步：使用首页快捷入口

首页提供：

- 🕘 **历史记录**：查看最近打开或播放过的内容
- ⭐ **我的收藏**：在独立滚动区域中查看并快速打开全部已收藏内容
- 🔗 **添加外部链接**：添加网络视频、音频、文档或直播源

## 🌐 来源管理

### 1. 添加本地文件夹

进入：

```text
来源 → 授权本地文件夹
```

在系统目录选择器中授权一个文件夹后，应用会扫描该目录并建立内容索引。

本地来源适合管理：

- 手机内部存储中的书籍
- 下载目录中的视频和音频
- 图片目录
- 本地漫画文件夹
- 外部存储或 SAF 授权目录

进入更深层的子文件夹时，ReadNest 会按需读取子目录内容，避免一次性扫描整个大目录。

### 2. 添加 WebDAV

进入：

```text
来源 → 添加 WebDAV 服务器
```

填写：

- 来源名称
- WebDAV 地址
- 用户名
- 密码

保存前建议先测试连接。连接成功后可以在内容库中浏览远程文件和文件夹。

适用场景包括：

- WebDAV 网盘
- alist 挂载服务
- 群晖 WebDAV
- 坚果云等兼容 WebDAV 的服务

### 3. 刷新来源

当远程目录发生变化时，在内容库中点击刷新来源。应用会尝试：

- 恢复已有条目
- 添加新文件
- 更新文件信息
- 清理云端已删除条目

### 4. 外部数据导入

应用会自动维护一个可写入的导入目录：

```text
外部数据导入
```

它用于保存：

- 系统分享进来的文件
- 外部应用分享进来的文件
- 首页添加的外部链接
- 从 SAF 或 WebDAV 缓存后转存的文件
- 解压后的 ZIP/CBZ 内容

只有外部数据导入目录中的本地副本适合直接编辑和保存。原始 WebDAV 文件、SAF 原始文件以及远端链接本身不会被直接写回。

## 📚 内容库使用方法

### 1. 浏览目录

点击文件夹即可进入下一级目录。返回上一级可以使用路径栏或返回按钮。

ReadNest 会按来源分别记忆：

- 上次浏览目录
- 来源筛选
- 排序方式

重新进入内容库时，会尽量恢复上一次的位置。

### 2. 搜索文件

在内容库搜索框输入文件名或文件夹名，即可筛选当前内容库中的条目。

搜索适合用于：

- 查找书名
- 查找某个视频
- 查找指定后缀文件
- 查找导入目录中的文件

### 3. 排序

内容库支持：

- 修改时间，新到旧
- 修改时间，旧到新
- 文件名，正序
- 文件名，倒序

排序设置会保存，下次进入内容库时继续使用。

### 4. 收藏

在文件或文件夹操作菜单中选择收藏后，该内容会出现在首页的“我的收藏”区域。

### 5. 重命名

对可管理的本地导入内容可以使用：

```text
长按条目 → 重命名
```

远程原始文件是否允许修改取决于来源和当前文件是否已经转存为本地副本。

### 6. 删除

删除文件或文件夹时，应用会根据内容来源提供相应选项。

对于导入目录中的本地副本，可以选择是否同时删除本地文件。删除远程条目不会自动删除远端服务器上的原始文件，除非该来源明确支持相应操作并且应用提供了对应权限。

### 7. 新建文件夹

进入“外部数据导入”目录后，可以在路径栏附近使用新建文件夹按钮：

```text
外部数据导入 → 新建文件夹
```

新建文件夹功能主要用于整理可编辑的本地导入内容。

## 🔗 首页添加外部链接

点击首页右上角的添加链接按钮，可以添加 HTTP/HTTPS 地址。

### 支持类型

- 🎬 普通视频
- 📺 M3U8 视频
- 🎧 音频
- 📄 PDF、EPUB、MOBI、DOCX、PPTX、XLSX
- 📡 M3U 直播源
- 📡 TXT 直播源
- 📚 TXT 小说或普通文本

应用会自动从 URL 中提取文件名，也可以手动修改文件名。

### M3U 和 TXT 的类型规则

M3U 和 TXT 在数据库中属于文本类型，但打开时会根据内容决定是否进入直播播放器：

```text
数据库类型：m3u / txt → 文本
实际打开方式：根据内容判断 → 直播播放器或文本/小说阅读器
```

TXT 直播源检测规则为：

1. 只检查文件前 1000 个字符
2. 查找 `,http://` 或 `,https://` 格式
3. 匹配数量至少 4 个，也就是超过 3 个
4. 相邻匹配的起点间隔必须小于 100 个字符
5. 满足规则后进入直播播放器，否则按普通 TXT 打开

M3U 则根据 M3U 频道内容解析，例如 `#EXTINF`、频道名和播放地址等。

## 📄 文档阅读器

### PDF

PDF 使用内置阅读器打开，支持按页阅读和进度记忆。

### EPUB

EPUB 阅读器支持：

- 📖 分页阅读
- 📑 章节目录
- ◀️ 上一页
- ▶️ 下一页
- 📊 阅读进度
- 🔊 从当前页朗读
- ⚙️ 阅读设置
- 中央区域点击显示或隐藏工具栏

朗读 EPUB 时，当前页面文字会按段落顺序交给 TTS 播放，页面完成后继续后续内容。

### MOBI

MOBI 会优先尝试转换为 EPUB：

```text
MOBI → EPUB 阅读器
转换失败 → 纯文本阅读器
```

转换过程中会显示格式转换提示。

### TXT 小说

TXT 阅读器支持：

- 自动识别常见编码
- UTF-8、UTF-16、GBK 等编码处理
- 自动章节切分
- 章节目录
- 上一页/下一页
- 阅读进度保存
- 朗读本章
- 阅读设置

如果 TXT 内容符合直播源规则，则会进入直播播放器；否则按小说或普通文本打开。

### Markdown

Markdown 阅读器支持：

- 标题
- 段落
- 列表
- 引用
- 代码块
- 表格
- 横向滚动表格
- 简单 HTML
- `<details><summary>` 展开/折叠
- Markdown 链接
- HTML 链接
- 编辑和保存

Markdown 中的链接点击后会调用系统外部应用打开，例如浏览器或其他适配该链接的应用。

### JSON

JSON 阅读器提供树状查看：

- `+` 展开对象或数组
- `−` 收起对象或数组
- 点击值复制内容
- 编辑 JSON
- 保存前进行格式校验

如果 JSON 格式错误，应用不会保存错误内容。

### 通用文本和源码

普通文本、配置文件和源码文件可以使用通用文本查看器打开，支持：

- 查找文本
- 查找上一个/下一个
- 行号
- 语法高亮
- 自动换行
- 按原格式横向查看
- 编辑保存

可编辑内容主要是外部数据导入目录中的本地副本。

## 🎬 视频播放器

视频播放器基于 mpv，适合播放本地视频、远程视频、M3U8 和直播源。

### 播放控制

播放器底部控制栏包含：

```text
[播放线路] [上一集] [播放/暂停] [下一集] [音轨/字幕]
```

其他控制入口位于播放器上方或工具栏中：

- 🔒 锁定/解锁播放器手势
- 📺 投屏
- ⓘ 视频信息
- ⏩ 倍速
- 📋 播放列表
- 🪟 小窗播放
- 🎧 后台播放
- ⛶ 全屏

### 播放线路

当当前频道存在多条线路时，播放线路按钮可点击。点击后会打开线路选择面板：

- 当前线路显示选中状态
- 显示线路地址
- 选择其他线路后重新建立播放器
- 尽量从当前记忆位置继续播放

只有一条线路时，播放线路按钮会置灰。

### 播放列表

播放列表会根据内容类型自动组织：

- 普通视频：聚合同目录、同来源的视频
- 直播源：显示频道列表
- 直播源分组：支持 M3U 的 `group-title` 和 TXT 的分组标记
- 普通列表：使用“全部”分组

播放列表支持：

- 分组下拉筛选
- 正序/倒序
- 标题搜索
- 当前分组内实时匹配数量
- 查找上一个/下一个
- 自动定位匹配项
- 大列表懒加载

即使列表包含大量条目，也只会构建当前屏幕附近的列表项，以减少滚动卡顿。

### M3U 频道图片

如果 M3U 的 `#EXTINF` 行包含 `tvg-logo` 参数，频道列表会在标题左侧显示频道图片：

```text
#EXTINF:-1 tvg-logo="https://example.com/logo.png" group-title="新闻",频道名称
https://example.com/live.m3u8
```

有图片时显示 `50×40` 的图片区域；没有图片或图片加载失败时显示播放图标，不会产生空白图片占位。

### 远程视频和 M3U8

应用会根据实际媒体内容判断是否为 HLS：

- URL 是 `.m3u8`：按 HLS 播放
- HTTP 入口 302 跳转到 `.m3u8`：跟随跳转后按 HLS 播放
- 响应 Content-Type 是 MPEG URL：按 HLS 播放
- 响应内容包含 `#EXTM3U` 或 `#EXTINF`：按 HLS 播放
- MP4 等普通视频：按普通视频直连播放

因此直播源中出现 MP4 地址时，不会强制按 HLS 处理。

### 手势操作

播放器默认是解锁状态，支持：

- 单击：显示/隐藏控制栏
- 双击：快退或快进
- 左右拖动：调整播放进度
- 左侧上下拖动：调整亮度
- 右侧上下拖动：调整音量
- 长按：临时三倍速播放

点击左上方的锁定按钮后，以上播放器画面手势全部禁用。再次点击解锁后恢复。

锁定不会禁用工具栏按钮、播放列表按钮、投屏按钮或系统返回操作。

### 全屏和自动旋转

进入视频播放页后会启用视频自动旋转。全屏时可以根据设备方向旋转视频画面。

打开全屏播放列表后，应用会自动定位到当前选集；分组筛选、搜索和正序/倒序状态下也会按当前可见列表定位。

### 播放失败和重试

如果出现网络中断或播放失败：

- 应用可能自动重试一次
- 长时间缓冲会显示“重试”按钮
- 点击重试会重建播放器
- 切换选集或再次点击当前选集也会重建播放器
- 旧的错误文字、缓冲状态和重试按钮会随旧播放器一起清理

## 📦 CBZ / CBR 和压缩包

### CBZ

CBZ 通常是 ZIP 格式漫画压缩包，应用会读取其中的图片并按自然顺序展示。

### CBR

CBR 使用 RAR 容器。如果当前设备无法直接解码，建议：

1. 将 CBR 转换为 CBZ；或
2. 先解压为图片目录；或
3. 使用外部应用打开。

### ZIP / CBZ 管理

外部数据导入目录支持缓存、转存和解压压缩包。解压过程包含路径安全检查，避免压缩包中的异常路径写出目标目录。

## ❓ 常见问题

<details>
<summary><b>Q: 为什么 WebDAV 文件不能直接编辑？</b></summary>

远程文件默认作为原始来源保护，不直接写回服务器。可以先将文件缓存或转存到“外部数据导入”目录，再编辑本地副本。
</details>

<details>
<summary><b>Q: 为什么 TXT 有时进入小说阅读器，有时进入直播播放器？</b></summary>

TXT 会先检查前 1000 个字符中的频道地址格式。当前规则要求至少匹配 4 个 `,http://` 或 `,https://`，并且相邻匹配之间的起点间隔小于 100 个字符。满足规则才进入直播播放器，否则按普通 TXT 打开。
</details>

<details>
<summary><b>Q: M3U 和 TXT 在数据库中是什么类型？</b></summary>

M3U 和 TXT 在数据库中属于文本类型。打开时再根据文件内容判断是否为直播源，因此同一个 TXT 文件可以按小说或直播源分流。
</details>

<details>
<summary><b>Q: 为什么播放列表很多时仍然可以滚动？</b></summary>

播放列表使用懒加载，只构建可视区域附近的条目，同时缓存分组和筛选后的索引。分组、搜索和排序会重新生成必要的索引，不会一次性创建全部播放条目。
</details>

<details>
<summary><b>Q: 为什么播放失败后点击重试会重新打开播放器？</b></summary>

重试会销毁旧播放器并重新创建播放链路，同时清理旧错误、缓冲和重试状态。这样可以恢复部分“有声音无画面”、网络断流或半初始化失败的问题。
</details>

<details>
<summary><b>Q: Markdown 中的链接如何打开？</b></summary>

Markdown 链接和 HTML `<a href="...">` 链接都会调用系统外部应用打开。HTTP/HTTPS 链接通常交给浏览器，其他协议会交给系统中已注册的应用。
</details>

<details>
<summary><b>Q: 视频画面误触怎么办？</b></summary>

点击播放器左上方的锁定按钮。锁定后会禁用单击、双击、长按、进度拖动、音量手势和亮度手势；工具栏按钮仍可以正常使用。再次点击锁图标即可解锁。
</details>

<details>
<summary><b>Q: 如何切换直播源线路？</b></summary>

当频道有多个播放地址时，播放器底部会启用“播放线路”按钮。点击后选择线路即可，单线路频道的按钮会置灰。
</details>

<details>
<summary><b>Q: 如何恢复上次的阅读或播放位置？</b></summary>

应用会自动保存文档阅读进度、音频播放位置和视频续播位置。重新打开同一内容时会尽量恢复到上次位置。
</details>
